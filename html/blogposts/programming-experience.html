Mjn ervaringen met programmeren

Middelbare school

Op het middelbaar heb ik de les Informatica gevolgd. Die lessen waren een soort ICT les voor basis concepten over het internet. We hebben dingen geprogrammeerd en tech gebruikt die je niet vaak tegenkomt. Ik ben in die les in contact gekomen met de Raspberry Pi en hoe je die kan gebruiken en dus ook Linux voor de eerste keer.
Wat betreft echt programmeren hebben we een weer-website gemaakt. De HTML en CSS waren zelf gemaakt (en zagen er nog slechter uit dan deze website), terwijl de javascript aan ons gegeven was omdat het nog te geadvanceerd was om ons te laten doen. Daarnaast hebben we een rekenmachine gemaakt in Windows Forms. Als laatste heb ik met de Unity engine een spel gemaakt met C#. Het spel is te spelen op deze website als je naar de navigatiebar gaat en 'game' klikt.

Vrije tijd

In mijn vrije tijd heb ik ook geëxperimenteert met de Unity engine, maar nooit iets concreets gemaakt. Het meeste wat ik heb gedaan in mijn vrije tijd is Python gebruiken. Ik heb Python gebruikt om GET requests te sturen naar een server om data op te halen en het in een tekst bestand stoppen. Die data was van een spel dat ik dan actief speelde terwijl mijn python script bezig was zodat ik de data kon inzien later.
